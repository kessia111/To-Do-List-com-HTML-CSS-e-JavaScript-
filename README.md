Uma aplicação de lista de tarefas (To Do List) desenvolvida para praticar os fundamentos de HTML, CSS e JavaScript.
✅ Adicionar novas tarefas
🗑️ Remover tarefas
☑️ Marcar tarefas como concluídas
💾 Gerenciamento das tarefas através de JavaScript
🎨 Interface simples e responsiva
